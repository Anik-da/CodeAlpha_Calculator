# Quantum Calc - Futuristic Glassmorphism Calculator

A professional, responsive, and futuristic-looking calculator web application built with HTML, CSS, and JavaScript.

![Quantum Calc Mockup](https://raw.githubusercontent.com/Anik-da/CodeAlpha_Calculator/main/preview.png) *(Preview image placeholder)*

## 🚀 Live Demo
**[https://codealpha-calculator.web.app](https://codealpha-calculator.web.app)**

## ✨ Features
- **Modern UI**: Dark mode with a sophisticated glassmorphism effect and glowing background blobs.
- **Scientific Mode**: Toggleable panel featuring:
  - Trigonometry: `sin`, `cos`, `tan`
  - Algebra: `sqrt`, `pow` (xʸ)
  - Parentheses for complex expressions
- **Core Operations**: Basic arithmetic (`+`, `-`, `×`, `÷`), percentages, and decimal support.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
- **Keyboard Support**: Complete numeric and operator keypad support.
- **Firebase Integrated**: Connected to Firebase for analytics and hosting.

## 🛠️ Built With
- **HTML5**: Semantic structure.
- **CSS3**: Vanilla CSS with custom properties, Grid, Flexbox, and backdrop filters.
- **JavaScript**: Modular ES6 logic for calculation and state management.
- **Firebase**: Hosting and Real-time Analytics.

## 📂 Project Structure
- `index.html`: Main application structure.
- `style.css`: Modern glassmorphism theme and animations.
- `script.js`: Core calculator logic and Firebase integration.
- `firebase.json`: Hosting configuration.
