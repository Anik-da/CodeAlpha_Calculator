# Quantum Calc - Futuristic Glassmorphism Calculator

A professional, responsive, and futuristic-looking calculator web application built with HTML, CSS, and JavaScript. Featuring a high-end initialization sequence and advanced calculation engine.

## 🚀 Live Demo
**[https://codealpha-calculator.web.app](https://codealpha-calculator.web.app)**

## ✨ Key Features
- **Futuristic Boot Sequence**: Interactive "Initialize System" splash screen for a premium user experience.
- **Glassmorphism UI**: Sophisticated dark mode theme with neon accents, backdrop filters, and dynamic background blobs.
- **Advanced Calculation Engine**: 
  - Mixed-mode support (combine basic and scientific functions in one expression).
  - High-precision rounding (handles floating-point issues like `0.1 + 0.2`).
  - Auto-closing parentheses for faster input.
  - Degree-based trigonometric calculations.
- **Scientific Mode**: Toggleable panel featuring `sin`, `cos`, `tan`, `sqrt`, and `pow` (xʸ).
- **Responsive & Zero-Scroll**: Fully optimized for mobile with a non-scrolling, viewport-aware layout.
- **Pro Keyboard Support**:
  - Full numeric and operator keypad mapping.
  - **Shift Key Shortcuts**: Hold Shift to access scientific functions instantly (`S` for sin, `C` for cos, etc.).
  - `Delete`/`Escape` for clearing.
- **Firebase Integrated**: Hosted on Firebase with real-time analytics.

## 🛠️ Built With
- **HTML5**: Semantic structure and SVG integration.
- **CSS3**: Vanilla CSS with custom properties (CSS Variables), Grid, Flexbox, and complex animations.
- **JavaScript**: Modular ES6 logic for calculation, state management, and keyboard event handling.
- **Firebase**: Hosting and Real-time Analytics.

## 📂 Project Structure
- `index.html`: Main application structure and initialization screen.
- `style.css`: Modern glassmorphism theme, mobile optimizations, and animations.
- `script.js`: Core calculator logic, keyboard shortcuts, and system initialization.
- `firebase.json`: Hosting and deployment configuration.
